# Hello Popup

Tiny Kotlin Android app. Opens a floating, resizable popup that says "hello world".

- Drag the title bar to move
- Drag the ◢ corner to resize
- Tap ✕ to close

First launch asks for "Display over other apps" permission.

Build: push to `main`; GitHub Actions uploads `HelloPopup-debug` (the APK) as a run artifact.
